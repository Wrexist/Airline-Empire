# UI polish sweep — 11 September 2026

## Scope and evidence

Reviewed the shared SwiftUI components and the Home, Airline, Finance, World,
airport browsing, onboarding and Pro presentation source. Visually inspected
the existing phone map/route captures, fleet and finance store composites, and
the yearly purchase review capture. These are previous-build evidence, not

native validation runs on GitHub's macOS runners. Fresh Finance, briefing and
route-detail captures from the changed app have now been visually inspected.

## Changes

- Route search keeps its list and search field mounted when nothing matches,
  with a Clear search action. Previously the empty branch removed search itself.
- Airport search stays above its results and offers Show all airports when empty.
- Shared chip rows wrap at natural widths, with a vertical layout at accessibility
  sizes and mirrored placement for right-to-left layouts. Route/fleet badges and
  World heading badges use this shared behavior.
- Finance and briefing stat grids use explicit equal spacing and switch to one
  column at accessibility sizes. All metric strips also use one column there,
  including the previously hard-coded four-metric case.
- Compact metrics share a value font and top alignment so multiline labels and
  emphasized values no longer stagger neighboring numbers. Labels grow vertically;
  numbers stay on one line with limited scaling.
- Home summary facts share available width evenly. Its large-text summary retains
  the existing two-fact limit and a trailing disclosure indicator.
- Dashboard and detail pages share 16-point horizontal, 8-point top and 24-point
  bottom spacing across briefing, finance, aircraft, routes, airports and World
  destinations. Empty-state titles wrap and remain centered.
- Onboarding selections and map-layer expansion respect Reduce Motion and use
  the shared selection animation.
- The existing detail-screen UI journey now checks zero-result route search,
  continued access to the search field, and restoration of the route after clearing.
